# 分群、標籤與自定義 SQL（v1.0，2026-10-15）— 對齊神策「分群」「標籤管理」「自定義 SQL」

> 依神策文件 segment_management、tag_management、custom_query（v3.0）逐項對照；原型「營運 › 分群與標籤」「分析 › 自定義 SQL」；契約 `backend/openapi.yaml` 的 Segments／SQL 標籤。角色對應本系統五種角色（docs/10 v0.4）。

## 1. 分群

| 神策功能 | 本系統 | 備註 |
|---|---|---|
| 三種創建：規則／導入／結果保存 | 相同；結果保存在事件／漏斗／留存／路徑／歸因結果點帶底線人數 | 結果保存分群不可編輯規則 |
| 規則類型：屬性、事件、分群、函數、行為序列 | 相同；規則組內「且／或」、嵌套規則、多規則組「交／併／差」 | 規則可拖動、複製 |
| 預估（1/16 抽樣，可配置） | `/v1/segments/estimate`；ClickHouse `SAMPLE 1/16` | 預估不寫審計明細，只記次數 |
| 排序與截取：屬性／事件聚合排序；前 N／區間；個數或百分比 | 相同 | 用於「取最高價值前 10%」類需求 |
| 導入：匹配任一 ID 欄位（不含 OneID）或用戶屬性；保留未匹配 ID；txt／csv | 相同；先做 L4 欄位掃描，命中即拒 | 保留未匹配 ID 會建新用戶並 ID-mapping，不可刪 |
| 更新：手動／例行（時間範圍、頻率、最早計算時間）；手動 1 版、例行版本上限 | 相同；存儲設定需「計算結果存儲配置」權限（系統管理員／資訊管理／數位經營） | 例行頻率建立後不可改 |
| 計算失敗告警；多時區 | 相同（Grafana → 值班群組；時區在建立時指定） | |
| 列表：搜尋、篩選、下載、存儲設定、回收站（恢復／徹底刪除） | 相同；回收站保留 15 天 | 徹底刪除限系統管理員 |
| 詳情：基礎資訊、規則、結果數下鑽、血緣、歷史版本（看規則／下鑽／另存／下載）、編輯、更新、暫停／啟動、複製 | 相同 | |
| 分群推送（版本結果 → 目標系統；推送記錄） | Webhook／Kafka／GCS（docs/14） | 不做廣告平台 |
| 狀態：運行中／已暫停；計算中／成功／失敗／取消 | 相同 | |
| 功能權限 10 項；用戶範圍（分支機構限定） | 行銷：新建（需審批）；數據分析：新建；數位經營：審批、管理、存儲配置；系統管理員：全部；用戶範圍保留給自訂角色 | 五種角色皆全域 |
| 上限 500 個／專案 | 相同 | |

分析頁引用分群：篩選與分組可選「最新結果」「動態匹配（事件日期 = basetime）」「自定義版本」；注意 T+1 計算的 basetime 比行為日期晚一天。

## 2. 標籤

| 神策功能 | 本系統 |
|---|---|
| 十種創建方式（已實作五種：自定義標籤值、SQL、基礎指標值、首末次特徵、RFM；見 `tags/service.py`）：自定義標籤值（≤24 值）、基礎指標值（總次數／總和／均值／最大／最小／去重數；按百分比／數值區間／離散值分層）、首次末次特徵、事件偏好屬性、行為分布結果、運算標籤（四則／T±N／日期間隔）、RFM、SQL（五種型別）、生命週期（增長模型 5 層或自定義，附洞察報告）、導入 | 相同；精靈第 2 步依方式切換表單 |
| 更新：手動／例行（每天／每週多選／每月含倒數；時間範圍；最早計算時間）；存儲 1–100 版；告警 | 相同 |
| 列表：搜尋（顯示名／名稱／備註）、篩選（型別、有無資料、規則可用、計算狀態、更新方式、狀態、創建方式、創建人、時間）、查看分布、下載、回收站、存儲設定 | 相同 |
| 詳情：資訊、血緣（含結果依賴的上游 basetime）、分布（排序／數量）、歷史詳情、變更記錄；編輯、啟停、審批、終止計算、回溯 | 相同 |
| 審批中心（通過／退回／拒絕） | 行銷／數據分析建立 → 數位經營審批；系統管理員直建 |
| 自定義欄位（字串／日期；文字框、單選、多選、日期） | 所屬部門、需求提出人、需求類別 |
| 權限：查看／新建／導入保留未匹配 ID／管理／存儲配置／查看回收站／恢復／徹底刪除；審批權限 | 對應五種角色（docs/10） |
| 上限 500 個／專案 | 相同 |

儲存：`dmp.user_tags`（tag_id, basetime, one_id_uint, tag_value, Bitmap）；每個 basetime 一版；分析查詢以 `dictGet`／Bitmap 交併差使用（docs/04 §6、docs/09）。

## 3. 自定義 SQL

| 神策功能 | 本系統 |
|---|---|
| 前提：自定義 SQL 功能權限 + 數據表數據權限；事件表／用戶表行權限、列權限、脫敏 | 數據分析、資訊管理、系統管理員；數據表權限由資訊管理在「數據表管理」分發 |
| 數據庫表目錄（表、欄位、型別；插入表名／查詢語句）；函數目錄；元事件輔助 | 相同（events、users、user_tags、segment_members、dim_*、id_map（限資訊管理）、中間表） |
| 編輯區：格式化、解釋、清空、動態參數；最多 5 條同時運行 | 相同；EXPLAIN 顯示分區裁剪、掃描估算、遮罩與行級規則 |
| 結果：預覽 1000 列（大量取數走非同步匯出任務：經審批、浮水印、審計，上限由系統管理員設定，預設 10 萬列，docs/26 衝突 4）；Excel／CSV 下載；複製前 100 列；可視化（表格、折線、柱狀、堆疊柱、柱線、環圖；X／Y≤5／分組≤5／排序／分組值前 10–50） | 相同；下載走匯出審批與浮水印 |
| 查詢記錄：30 天內最近 100 條；插入編輯器；成功者可下載 | 相同 |
| 已存查詢目錄（分組）；保存至概覽／書籤；動參在概覽可改、日期型可綁全局日期 | 相同 |
| 保存到中間表（SQL 任務 → 任務管理 + 數據表管理）；添加到業務集市 | 相同（中間表可被標籤與分析引用） |
| 跨專案查詢（平台帳號） | 保留：證券示範專案為單一專案 |
| 脫敏預校驗：SQL 涉及脫敏欄位直接報錯 | 相同；另限制唯讀（SELECT／WITH），DDL／DML 拒絕 |

執行引擎：Trino 做權限與遮罩改寫後下推 ClickHouse；資源群組 `dmp`（掃描 2 TB／查詢、逾時 300 s、每人 5 併發）；審計 `query.sql`、`export`。
